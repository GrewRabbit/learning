# Git 提交规范

> 适用角色：所有 Agent | 优先级：最高

---

## 一、提交语言

**CRITICAL**：提交描述必须使用**中文**。

---

## 二、提交格式

```
<类型>: <简短描述>
```

### 类型

| 类型 | 说明 |
|------|------|
| 新增 | 新功能、新模块 |
| 修复 | Bug 修复 |
| 优化 | 性能优化、代码改进 |
| 重构 | 代码重构（无功能变化） |
| 文档 | 文档更新 |
| 测试 | 测试相关 |
| 样式 | UI 样式调整 |

### 示例

```
新增: 用户登录页面及表单验证
修复: 解决用户登录时验证码不显示的问题
优化: 减少 Dashboard 页面首屏加载时间
重构: 将 UserService 拆分为独立模块
```

---

## 三、Git 安全协议

- **禁止**更新 git config
- **禁止**执行破坏性命令（`push --force`、`reset --hard`、`checkout .`、`clean -f`、`branch -D`），除非用户明确要求
- **禁止** force push 到 main/master
- 提交前使用 `git add <specific-files>` 而非 `git add -A`

---

## 四、提交前检查

1. 不提交包含敏感信息的文件（`.env`、credentials 等）
2. 不提交与变更无关的文件
3. 确保提交描述准确反映变更目的
