# 开发环境迁移指南

**日期**：2026-08-18
**类型**：文档
**影响范围**：整个开发环境（源码 + git 忽略的运行数据 + 项目外配置）

## 一、迁移对象与决策

| 项目 | 决策 | 说明 |
|------|------|------|
| 源码 / 配置 / 测试 / docs | ✅ 包含 | git 跟踪的全部 535 个文件 + 未提交改动 |
| `.git` 历史 | ✅ 包含 | 保留提交历史与分支，目标机可直接 pull/push |
| `.env.local` | ✅ 包含 | 含真实 API 密钥，压缩包需保密保管 |
| `.data/`（FsHtmlCache / 日志 / 中间产物） | ✅ 包含 | 本地存储统一目录（自 2026-08-20 起，替代原 `data/`） |
| `workZone/`（解题产物） | ✅ 包含 | 编译二进制与字体 |
| `tmp/`（subagent 缓存） | ✅ 包含 | 体积小，保留无害 |
| `coverage/`、`log`、`tsconfig.tsbuildinfo` | ✅ 包含 | 体积小 |
| `node_modules/`（540M） | ❌ 排除 | 目标机 `npm ci` 重建 |
| `.next/`（199M 构建缓存） | ❌ 排除 | 目标机 `npm run build` 重建 |
| `.opencode/node_modules/`（63M） | ❌ 排除 | 目标机 `npm install` 重建 |

> 压缩包内将保留项目根 `.gitignore` 原样，目标机解压后 `git status` 行为与迁移前一致。

## 四、目标机安装步骤

### 1. 前置要求

- 同为 **Linux x64**，磁盘剩余 ≥ 3G
- Node.js **≥ 20**（推荐 24.x，与源一致），npm ≥ 10
- 解压工具：`tar`、`gzip`
- **g++-13**（集成测试用真实 g++ 编译 CodeValidator；GESP 官方要求 13.2.0，源环境经 `ubuntu-toolchain-r/test` PPA 安装。缺失时 `npm test` 中 `tests/integration-tests/orchestrator.test.ts` 全挂）

### 2. 解压

```bash
mkdir -p /var/learning
tar -xzf /var/gesp6-web-html-YYYYMMDD.tar.gz -C /var
# 解压后应得到 /var/learning/
```

### 3. 校验环境变量

```bash
cd /var/learning
diff <(grep -E '^[A-Z_]+=' .env.local | sed 's/=.*//' | sort) \
     <(grep -E '^[A-Z_]+=' .env.local.example | sed 's/=.*//' | sort)
```

- `.env.local` 随包迁移，含真实密钥，**禁止提交 git、禁止外发**。
- 若目标机密钥需更新，参照 `.env.local.example` 的键名逐一替换。
- 启动时服务端会校验缺失的必需环境变量，按报错补齐即可。

### 4. 安装依赖

```bash
npm ci        # 锁定版本安装。勿加 --omit=optional：vitest 依赖原生可选包 @rollup/rollup-linux-x64-gnu，
              # 跳过可选依赖会导致 npm test 报「Cannot find module @rollup/rollup-linux-x64-gnu」
```

### 5. opencode 技能依赖（可选）

```bash
cd /var/learning/.opencode && npm install   # 重建技能工作流依赖
```

### 6. 构建与验证

```bash
cd /var/learning
npm run type-check   # 类型检查
npm run build        # 生产构建（重建 .next）
npm run lint         # 代码规范
npm test             # 单元 + 集成（全 mock，无需模型）
npm run dev          # 开发服务器，访问 http://localhost:3000
```

### 7. 系统依赖与 Playwright 浏览器（跑 E2E 才需要 Playwright）

```bash
# g++-13（集成测试必需，Ubuntu 22.04 默认源无此包，走 PPA 与源环境一致）
add-apt-repository -y ppa:ubuntu-toolchain-r/test
apt-get update
apt-get install -y g++-13
g++-13 --version   # 应输出 13.x

# Playwright 浏览器（跑 E2E 才需要）
npx playwright install chromium
```

## 六、项目外配置（压缩包不含，需手工迁移）

以下内容在项目目录之外，**不随压缩包迁移**，需目标机手工配置：

| 配置 | 路径 | 内容 | 迁移方式 |
|------|------|------|---------|
| opencode 全局配置 | `~/.config/opencode/opencode.json` | MCP 服务器 context7/pencil 及 API key | 整目录复制 `~/.config/opencode/` |
| opencode 全局代理 | `~/.config/opencode/agents/`、`polish.jsonc`、`tui.json`、`acp.jsonc` | 全局 agent 与 UI 配置 | 整目录复制 |
| Playwright 浏览器 | `~/.cache/ms-playwright/` | chromium、ffmpeg 二进制 | 目标机 `npx playwright install` 重建 |
| npm 全局包 | `/usr/lib/node_modules` 或 `~/.npm-global` | 全局 CLI 工具 | `npm ls -g` 对照安装 |

## 七、注意事项

1. **密钥安全**：压缩包含 `.env.local` 真实密钥，传输建议走内网/加密通道，解压后 `chmod 600 .env.local`，压缩包用完即删或妥善保管。
2. **原生模块**：虽然同为 Linux x64，但 `npm ci` 会按目标机 CPU 指令集重新编译 sharp/esbuild 等原生模块，勿直接把旧 `node_modules` 拷过去。
3. **SSO / 模型可达性**：SSO IdP 与各模型 API 均走公网域名（.env.local 中的 URL），目标机需能访问外网；内网代理环境需配置 `HTTPS_PROXY`。
4. **未提交改动**：压缩包包含 2 处未提交改动（middleware 相关），迁移后先确认是继续提交还是回退。
5. **`.data/` 本地存储**：本地缓存/日志/中间产物统一存 `.data/`（`GESP6_CACHE_DRIVER=fs` 时缓存根 `.data/gesp6`）；若目标机想重置缓存，删掉 `.data/` 即可，不影响功能。
6. **权限**：解压以 root 执行则文件属主为 root，如需其他用户运行需 `chown -R` 调整。
7. **`.git` 与远端**：压缩包含 `.git`，远端地址（`origin`）随迁移保留，目标机可直接 `git fetch` / `git pull`。
