# 登出回跳解析为绝对 URL

**日期**：2026-08-11
**类型**：修复
**影响范围**：`/api/sso/logout` 登出端点、end_session 自动提交页、登出回跳落地页

## 变更背景

上一提交（c796be0）为登出按钮默认携带 `post_logout_redirect_uri='/'`，点击退出后浏览器跳转至端_session 自动提交页，POST 至 IDP `https://auth.happyrabbit.top/api/sso/logout`。但真实 IDP 校验失败，返回：

```
{"error":"invalid_request","error_description":"Invalid url"}
```

根因：集成指南 `docs/integration-guides/sso-idp-sp-integration-guide.md` 规定 `post_logout_redirect_uri` **必须是绝对 URL**，并在客户端注册的 `postLogoutRedirectUris` 白名单内。我方将相对路径 `'/'` 原样写入隐藏字段转发给 IDP，IDP 无法解析相对值 → 400 invalid_request。

## 变更内容

- `app/api/sso/logout/route.ts`：白名单校验仍接受相对路径 `/`（FR-022 同源语义保持），但构造 end_session form 前用请求 origin 将相对值解析为绝对 URL（`new URL(effectiveRedirect, request.url).toString()`），如 `/` → `http://localhost:3000/`，再传给 IDP。
- `app/api/sso/logout/__tests__/route.test.ts`：断言由 `value="/"` 更新为绝对地址 `value="http://localhost/"`（测试请求 origin 为 `http://localhost`）。

注：本地开发需 IDP 客户端将 `http://localhost:3000/` 登记进 `postLogoutRedirectUris` 白名单（已通过真实 IDP 实测验证：返回 307 回跳 `http://localhost:3000/?state=...` 并清除 IDP 会话 cookie）。
