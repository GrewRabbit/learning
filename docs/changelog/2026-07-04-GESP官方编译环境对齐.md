# 对齐 GESP 官方 C++ 编译环境

**日期**：2026-07-04
**类型**：优化
**影响范围**：代码验证器（code-validator）、LLM skill 提示词（gesp6-skill.md / SKILL.md）、系统环境（GCC 版本）

## 变更背景

GESP 官方要求 C++ 开发环境为：
- Dev C++ 5.11，GCC ≥ 4.9.2
- g++ 13.2.0，编译选项：`-O2 -std=c++11 -DONLINE_JUDGE`

本项目原编译环境与 GESP 官方不一致：

| 项目 | 原配置 | GESP 官方要求 |
|------|--------|--------------|
| GCC 版本 | 11.4.0（Ubuntu 22.04 自带） | g++ 13.2.0 |
| 编译标准 | `-std=c++17` | `-std=c++11` |
| 宏定义 | 无 | `-DONLINE_JUDGE` |

差异导致的问题：LLM 可能生成 C++14/17 特性代码（如结构化绑定、`if constexpr`），在项目环境（c++17）编译通过，但在 GESP 官方环境（c++11）编译失败，影响考生实际使用。

## 变更内容

### 系统环境：安装 GCC 13

- 通过 `ubuntu-toolchain-r/test` PPA 安装 `gcc-13` / `g++-13`（版本 13.4.0，属于 GCC 13 系列，与 GESP 官方 13.2.0 同系列）
- 安装命令：
  ```bash
  add-apt-repository ppa:ubuntu-toolchain-r/test -y
  apt update && apt install -y gcc-13 g++-13
  ```
- 采用 `g++-13` 显式调用（不修改系统默认 `g++`，避免影响其他组件）

### 代码验证器

- **code-validator.ts**：
  - `checkGppAvailable()`：检测命令 `g++` → `g++-13`
  - `compile()`：编译命令 `g++ ... -std=c++17 -O2` → `g++-13 ... -O2 -std=c++11 -DONLINE_JUDGE`
  - 日志消息同步更新（"g++ 可用性检查" → "g++-13 可用性检查" 等）
  - 错误消息更新（"g++ 编译器不可用" → "g++-13 编译器不可用"）

### LLM Skill 提示词

- **gesp6-skill.md**（程序 skill）：
  - "七、C++ 代码规范" 增加编译环境子章节
  - 明确编译器 g++ 13.2.0、编译选项 `-O2 -std=c++11`
  - 列出 C++11 允许特性（auto、lambda、range-based for、emplace_back 等）和 C++14/17 禁止特性（结构化绑定、if constexpr、std::optional 等）
  - 提示"使用 C++14/17 特性会导致编译失败并触发修正循环"

- **SKILL.md**（原始 skill）：
  - 第三步编码规范增加编译环境说明（同上）
  - 两处编译命令更新：`g++ -O2` → `g++-13 -O2 -std=c++11 -DONLINE_JUDGE`（L120、L273）

### 测试

- **code-validator.test.ts**：`g++` → `g++-13`（检测命令、describe 块名称、skip 日志）

## 后续影响 / 注意事项

1. **部署到新服务器时必须安装 g++-13**：需执行上述 PPA 安装命令，否则 CodeValidator 会返回 `GESP6_GPP_UNAVAILABLE` 并降级跳过编译验证
2. **Dockerfile 需更新**（如有）：构建镜像时需加 `add-apt-repository ppa:ubuntu-toolchain-r/test && apt install gcc-13 g++-13` 步骤
3. **C++11 约束影响 LLM 生成**：skill 明确禁止 C++14/17 特性，LLM 生成的代码将更严格地遵守 C++11 标准，与 GESP 官方环境完全一致
4. **`-DONLINE_JUDGE` 宏**：编译时定义此宏，LLM 生成的代码可用 `#ifdef ONLINE_JUDGE` 控制调试代码（skill 未主动说明此宏，但编译器会定义）
5. **GCC 版本说明**：安装的是 13.4.0（PPA 最新版），GESP 官方写的是 13.2.0，属于同一 GCC 13 系列，C++11 标准支持完全一致
6. **不影响系统默认 g++**：仍为 11.4.0，其他需要 g++ 的组件不受影响
