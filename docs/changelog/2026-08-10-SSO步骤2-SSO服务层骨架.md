# SSO 步骤 2：lib/sso 骨架（types / schemas / pkce / config）

**日期**：2026-08-10
**类型**：新增
**影响范围**：`app/lib/sso/` 服务层骨架（M2/M8）、`app/lib/sso/__tests__/`

## 变更背景

实施 SSO 集成架构 §11 步骤 2（模块 M2/M8）：搭建 SSO 服务层基础模块。此层为后续 Discovery / OAuth / id_token 验证 / token 生命周期等模块提供类型、schema、PKCE 工具与配置读取的统一基础。

## 变更内容

### `app/lib/sso/types.ts`（新增）

- 纯类型模块（`import type`）：`SsoConfig`（issuer / clientId / clientSecret? / idTokenVerifyMode / refreshTokenMaxAgeDays / mockEnabled / retryMax / scope / publicIssuer? / publicClientId? / publicRedirectUri?）、`IdTokenVerifyMode`、`IdTokenClaims`、`AccessTokenClaims`、`TokenResponse`、`DiscoveryDocument`、`ExchangeCodeParams`、`RefreshTokenParams`、`EndSessionParams` 等

### `app/lib/sso/schemas.ts`（新增）

- Zod 校验：`authorizeFormSchema`（登录发起 form body）、`callbackQuerySchema`（回调 query）
- nonce 最小长度按 spec-sso-auth FR-002 定为 32（初版误用 16，经 nonce 修正修正）

### `app/lib/sso/pkce.ts`（新增）

- 同构纯函数（仅 Web API，AR2-011）：`generatePkcePair()`（code_verifier ≥43 + code_challenge = base64url(SHA-256(verifier))）、`generateState()`、`generateNonce()`（state / nonce 均 ≥32 加密随机源，对应 auth spec FR-002 / FR-019）
- 供前端登录发起与登出编排复用

### `app/lib/sso/config.ts`（新增）

- `getSsoConfig(): SsoConfig`：读取 getSsoEnv 结果并做模块级缓存（validateEnv 模式，与既有 env 缓存一致）
