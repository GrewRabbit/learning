# /login 登录入口页落地（FR-030/D-005/M7）

**日期**：2026-08-11
**类型**：新增
**影响范围**：`/login` 路由（app/login/）、登录入口组件（components/auth/login-button.tsx 复用）、SSO 默认落地页测试断言

## 变更背景

全站登录墙（2026-08-11 业务裁决）下，middleware 未认证重定向目标为 `/login`，但代码库不存在该路由。本变更按已 approved 架构（arch-sso-v1.3.md §6、§4.1.1）落地 `/login` 登录入口页（FR-030），实现登录态粗检、已登录重定向回跳、returnTo 透传与登录发起（form POST /api/sso/authorize）。

## 变更内容

### app/login/page.tsx（新增，RSC）

- 登录态粗检：读 `sso_access_token` cookie 并解码 JWT payload 的 `exp`（仅 base64url 解码不验签，FR-016 语义，与 middleware 同思路）。
- 已登录 → `redirect()` 回 `returnTo`（经 `isSafeReturnTo` 校验并排除与 `/login` 或 `/{locale}/login` 规范化相等目标防死循环，FR-030/AR3-001），非法/缺失回退默认落地页 `/solve`（OQ-009）。
- 未登录 → 渲染 `LoginClient`（returnTo 透传 + 错误提示）。

### app/login/login-client.tsx（新增，'use client'）

- 复用 `LoginButton`（components/auth/login-button.tsx）发起登录，透传 RSC 已校验的 returnTo。
- 登录错误提示：仅展示错误码 + 安全通用文案，不展示原始 error.message（FR-026 脱敏）；错误码源为 URL query `error`（回调失败回跳预留位）。

### 测试断言同步（OQ-009：默认落地页 = /solve）

`token-cookie.ts` 的 `DEFAULT_RETURN_TO` 已由前序变更改为 `/solve`，本变更同步 3 个测试文件中的 6 处过期断言（原断言 `'/'`）：

- `app/lib/sso/__tests__/token-cookie.test.ts`：DEFAULT_RETURN_TO 断言
- `app/api/sso/authorize/__tests__/route.test.ts`：returnTo 非法回退默认落地页断言 ×3
- `app/api/sso/callback/__tests__/route.test.ts`：302 回默认落地页断言 ×2
