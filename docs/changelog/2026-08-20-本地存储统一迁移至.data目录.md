# 本地存储统一迁移至.data目录

**日期**：2026-08-20
**类型**：重构
**影响范围**：本地存储约定（`data/` → `.data/`）、`FsHtmlCache` 默认路径、迁移脚本源路径、`.gitignore`、运维文档、AGENTS.md

## 变更背景

为便于后期正式部署与更新，统一本地存储约定：**所有运行时本地数据（缓存、日志、程序生成的中间记录文件）统一存放于 `.data/` 目录，不再使用 `data/` 目录**。此前 FsHtmlCache 默认落盘 `data/gesp6`（gitignore `/data/`），根目录散落历史 `log` 文件与 `tmp/` 冗余副本；部署/更新时排除 `.data/` 即可，与源码目录清晰隔离。

## 变更内容

### 代码默认路径（`data/` → `.data/`）

- `app/lib/ai/services/html-cache.ts`：`GESP6_CACHE_FS_DIR` 默认值 `path.resolve(process.cwd(), 'data/gesp6')` → `'.data/gesp6'`
- `scripts/migrate-fs-cache-to-db.ts`：导入源根目录默认值同步改为 `'.data/gesp6'`，头部注释更新
- `app/lib/ai/services/fs-html-cache.ts`：`baseDir` 注释示例 `/data/gesp6` → `.data/gesp6`

### .gitignore

- 新增 `/.data/` 忽略（本地存储统一目录）
- 保留 `/data/` 忽略（历史兼容，新内容不再写入）
- `/log` 保留（并入 `.data/log/`）

### 文件系统清理（按「先备份再迁移」策略）

- 删除空目录 `data/`（内容已于 2026-08-20 备份删除）
- 根目录历史 `log`（22K，2026-07-05 调试日志）移至 `.data/log/2026-07-05-console.log`
- `tmp/gesp6-solution/`（3.4M，2026-08-11 skill 运行时冗余副本，与 `.opencode/skills/gesp6-solution/` 重复）移至 `.data/backup/gesp6-solution-20260811/`，`tmp/subagent_description.md` 移至 `.data/backup/`，删除 `tmp/` 目录

### 运维文档同步

- `docs/operations/日志排查指南.md`：fs 缓存检查路径 `data/gesp6` → `.data/gesp6`（3 处）
- `docs/operations/开发环境迁移指南-2026-08-18.md`：`data/` 缓存条目 → `.data/` 本地存储目录（2 处）
- `docs/operations/数据库整合执行计划.md`、`数据库整合实施进度.md`：回退方案缓存根 `data/gesp6` → `.data/gesp6`

### 项目约定

- `AGENTS.md`「关键约定」新增本地存储约定条目（.data/ 用途与不使用 data/ 的说明）
- `.opencode/rules/global/changelog.md` 与 `.trae/rules/global/changelog.md`：`GESP6_CACHE_FS_DIR` 默认值示例更新为 `.data/gesp6`

## 后续影响 / 注意事项

- 新增任何本地存储（缓存、日志、中间产物）一律写入 `.data/` 子目录，禁止再创建 `data/` 目录
- 部署/更新时排除或整体迁移 `.data/` 即可（gitignore 已覆盖），不影响源码
- 历史文档（changelog/reviews/specs）中 `data/gesp6` 引用为历史记录，按「更新日志只追加不修改」规则不改动
