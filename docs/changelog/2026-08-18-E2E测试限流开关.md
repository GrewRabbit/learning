# E2E 测试限流开关与 dev:test 脚本

**日期**：2026-08-18
**类型**：优化
**影响范围**：middleware.ts、package.json、playwright.config.ts、tests/e2e-tests/specs/*

## 变更背景

E2E 测试多 worker 对单个 dev server 密集请求时，中间件默认 `20 次/分/IP` 限流触发
`GESP6_RATE_LIMITED`（429），使 `/solve` 等页面加载返回 JSON 而非页面，导致
navigation / platform-input / validation / smoke 等用例假失败。此前为硬编码常量，无
法在测试环境关闭。

## 变更内容

### middleware.ts

- 限流开关与环境变量化（供测试/开发便利，生产保持默认）：
  - `GESP6_RATE_LIMIT_ENABLED`：`'0'` / `'false'` 时跳过限流
  - `GESP6_RATE_LIMIT_MAX`：覆盖每分钟配额（默认 20）
- 注意：Next.js 构建时内联 middleware 引用的 `process.env`，生产覆盖须在构建时注入。

### package.json

- 新增 `dev:test` 脚本：`GESP6_RATE_LIMIT_ENABLED=0 GESP6_RATE_LIMIT_MAX=100000 next dev`
  （测试用 dev server，关闭限流供 E2E 密集请求）

### playwright.config.ts

- `webServer.command` 由 `npm run dev` 改为 `npm run dev:test`（E2E 自动起限流关闭的服务）

### tests/e2e-tests/specs/*

- 各 spec 头部补充运行前提注释：E2E 需 `npm run dev:test` 起服务（playwright.config
  已自动使用；手动起服务若用 `npm run dev` 会因限流假失败）

## 后续影响 / 注意事项

- 生产部署保持默认限流（20 次/分/IP）；如需覆盖须在构建时注入环境变量。
