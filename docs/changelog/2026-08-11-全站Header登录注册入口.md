# [变更标题] 全站 Header 登录注册入口

**日期**：2026-08-11
**类型**：新增
**影响范围**：全站页面布局、Header 组件（app/layout.tsx、components/site-header/*、components/ui/dropdown-menu.tsx）、SSO 环境变量、部署配置示例

## 变更背景

此前已完成 SSO SP 登录到 IDP 的服务与部分页面开发（middleware.ts 服务端认证、/login 登录页）。本次改造前置补齐全站页面顶部的 Header（页头），统一未登录用户注册/登录入口与已登录用户的用户中心/登出入口，并在用户需求确认后落地为「简方案 + 实施」（详见 `docs/全站Header改造-方案说明.md`）。

## 变更内容

### Header 组件（新增）

- 新增 `components/site-header/site-header.tsx`（RSC）：服务端读取 `sso_access_token` cookie 粗检 JWT exp 判定登录态（复用 login 页同款 `decodeJwtExp` 逻辑），将 `isAuthenticated` 传给 HeaderBar。
- 新增 `components/site-header/header-bar.tsx`（client）：除登录页外全站渲染；`/login` 与 `/{locale}/login` 隐藏 Header；左侧 Logo（sm），右侧未登录显示「注册」（外链 IDP 注册页，`target=_blank`）+「登录」（复用 LoginButton）；已登录显示 UserMenu。
- 新增 `components/site-header/user-menu.tsx`（client）：已登录态右上角用户图标 Dropdown，「用户信息」（外链 SSO 用户中心）与「退出登录」（复用 LogoutButton）。
- 新增 `components/site-header/header-utils.ts` + `__tests__/header-utils.test.ts`：抽出可单测纯函数（URL 读取 fail-safe、路径判定、JWT exp 解码、会话有效性）。遵循项目测试栈约定（vitest environment=node，不引入 jsdom，渲染行为留给 E2E）。
- 新增 `components/ui/dropdown-menu.tsx`：基于 @radix-ui/react-dropdown-menu 的头下拉菜单封装（本次新增该运行时依赖）。

### 布局接入

- `app/layout.tsx`：body 顶层渲染 `<SiteHeader />`（LayoutClient 纯透传按原样保留）。

### 环境变量（新增两个，均为可选）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `NEXT_PUBLIC_SSO_DASHBOARD_URL` | 无（可选） | SSO 用户中心地址；缺失时 Header 隐藏「用户信息」入口（fail-safe 不渲染死链） |
| `NEXT_PUBLIC_SSO_REGISTER_URI` | 无（可选） | IDP 注册页地址；缺失时 Header 隐藏「注册」入口（fail-safe 不渲染死链） |

两变量为浏览器可见 URL，遵循既有 NEXT_PUBLIC_SSO_* 命名；URL 经 `new URL` 校验协议仅为 http/https（防 javascript: 注入）。`app/lib/env.ts` SsoEnvConfig 同步扩展两可选字段（缺失仅告警不阻断，保持常规+ mock 分支校验契约不变）。

## 配置 / 环境变量变化

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `NEXT_PUBLIC_SSO_DASHBOARD_URL` | 无（可选） | 用户中心地址（https://auth.happyrabbit.top/dashboard） |
| `NEXT_PUBLIC_SSO_REGISTER_URI` | 无（可选） | IDP 注册页地址（https://auth.happyrabbit.top/zh-CN/register） |

均为 NEXT_PUBLIC_ 前缀（浏览器可见、无敏感值），缺失不影响应用启动（Header 对应入口自动隐藏）。

## 后续影响 / 注意事项

- 已登录态的「用户图标 → 操作菜单」交互为客户端渲染，验证需真实 IDP 会话（`npm run test:e2e:sso` 或真机手动登录）。
- Header 未登录「登录」复用 LoginButton 的 `returnTo=usePathname()`：从任一业务页点击登录，登录成功后回落当前页。
- dist 部署无需迁移数据库；仅需在新环境补充两个可选环境变量（缺失时 Header 入口降级隐藏）。
