# 有道小图灵 URL 识别扩展

**日期**：2026-06-30
**类型**：修复
**影响范围**：接入层 platform 输入校验（`app/api/solve/route.ts` → `platforms.config.ts`）

## 变更背景

用户报告以下两种有道小图灵 URL 均被接入层拒绝，报错"内容不合法（platform 类型需为已配置平台的合法 https URL）"：

1. `https://oj.youdao.com/problem/7906?from=problems`（标准路径 + query string）
2. `https://oj.youdao.com/exercise/7/48/4924/1?title=简单排序`（练习路径）

curl 验证两种 URL 都返回 HTTP 200 且指向真实题目，应允许接入。

**根因**：

- `platforms.config.ts` 中 youdao 的 `urlPattern` 为 `/^https:\/\/oj\.youdao\.com\/problem\/(\d+)$/`，`$` 锚点拒绝任何 query string；
- 该正则仅匹配 `/problem/{id}` 路径，对 `/exercise/{a}/{b}/{problemId}/{seq}` 形式的练习路径完全不支持；
- 因此 Zod 校验阶段直接判定为"未配置平台"，返回 400。

经 curl 验证：`/exercise/7/48/4924/1` 与 `/problem/4924` 指向同一题目（题号 4924，"谁考了第k名"），题号位于 exercise 路径的倒数第二段。

## 变更内容

### platforms.config.ts

- 扩展 youdao `urlPattern`，同时支持两种路径 + 可选 query string：
  - `/problem/{problemId}`
  - `/exercise/{a}/{b}/{problemId}/{seq}`（题号在倒数第二段）
- 重写 `idExtractor`：用 `new URL()` 解析 pathname，分别匹配两种格式提取题号；非法 URL 通过 try-catch 返回 null。
- 配置注释补充两种 URL 形态与题号位置的说明。

### route.test.ts

新增 3 个测试用例覆盖扩展后的 youdao URL 识别：

- 标准路径 + query string：`https://oj.youdao.com/problem/7906?from=problems` → `problemId=7906`
- 练习路径（无 query）：`https://oj.youdao.com/exercise/7/48/4924/1` → `problemId=4924`
- 练习路径 + 中文 query：`https://oj.youdao.com/exercise/7/48/4924/1?title=简单排序` → `problemId=4924`
