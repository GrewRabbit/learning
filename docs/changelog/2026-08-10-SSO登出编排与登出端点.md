# SSO 登出编排与登出端点（步骤 9）

**日期**：2026-08-10
**类型**：新增
**影响范围**：`/api/sso/logout` 端点、`app/lib/sso/logout-service.ts`、`components/auth/`（M7 UI 组件）、SSO 会话 cookie 生命周期

## 变更背景

SSO 专项第 9 步（架构 arch-sso-v1.2.md §11）：实现 SP-Initiated Logout 登出编排——revoke IDP token、清除本地会话 cookie、构造 end_session HTML form 自动提交页跳转 IDP，并提供登出 UI 入口组件。前置步骤已交付登录（M1）、令牌刷新（步骤 6）、认证守卫（步骤 8），本步骤补齐登出闭环。

## 变更内容

### app/lib/sso/logout-service.ts（新增，206 行）

登出编排服务单例 `logoutService`：

- `clearSessionCookies(response)`：清除 `sso_access_token` / `sso_refresh_token` / `sso_id_token` 三 cookie（httpOnly+sameSite=lax+path=/+maxAge:0，委托 token-cookie 同属性实现）
- `revokeTokens(accessToken?, refreshToken?)`：顺序 revoke access_token → refresh_token（token_type_hint 分别 `access_token`/`refresh_token`）；任一失败（error result 或异常）仅记 `logger.warn`（AUTH_TOKEN_REVOKE_FAILED）不阻断登出（FR-020）
- `isLogoutRedirectAllowed(candidate)`：复用 `isSafeReturnTo` 开放重定向语义（同源相对、拒 `//` 跨域 / `javascript:` / `data:`），再精确命中注册白名单（FR-022 更强白名单）
- `buildEndSessionPage({idTokenHint?, postLogoutRedirectUri?})`：经 discovery 取 `end_session_endpoint` 构造自动提交 form 页（AR1-002）——method=POST、enctype=x-www-form-urlencoded、隐藏字段 `id_token_hint`（缺失/不可用→回退 `client_id`，FR-019）/ `post_logout_redirect_uri`（白名单通过才带，FR-022）/ `state`（≥32 加密随机源，FR-021，复用 pkce）；页面 onload 自动 submit + noscript 手动按钮；id_token 为 PII 仅 POST body 不落 URL（AR2-008）

### app/api/sso/logout/route.ts（新增，99 行）

- 仅 POST（AR2-007）：GET → 405 METHOD_NOT_ALLOWED
- POST 编排（FR-019 顺序）：读三 token cookie → Zod 校验请求体 `post_logout_redirect_uri`（logoutFormSchema，仅格式/长度）→ 白名单校验（非法 → 400 AUTH_LOGOUT_REDIRECT_INVALID，**cookie 仍清**，FR-022 错误路径）→ revokeTokens（失败不阻断）→ clearSessionCookies → 无 redirect 200 `{success:true}`；有合法 redirect → 200 text/html end_session form 页；Discovery 失败 → 500 AUTH_IDP_DISCOVERY_FAILED（cookie 仍清）

- 登出 state 307 回传校验端点（FR-021 回跳校验）不在本步骤，为后续步骤遗留项
