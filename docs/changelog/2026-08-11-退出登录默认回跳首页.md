# 退出登录默认回跳首页

**日期**：2026-08-11
**类型**：修复
**影响范围**：Header 用户菜单登出按钮、`POST /api/sso/logout` 登出编排

## 变更背景

点击 Header 右上角用户菜单的「退出登录」后，浏览器停留在 `http://localhost:3000/api/sso/logout`，页面仅显示 `200 {success:true}`。原因是 `logout-button.tsx` 默认不携带 `post_logout_redirect_uri` 隐藏字段，服务端据此走「本地登出 200」JSON 分支，未触发 IDP 全局登出回跳。

## 变更内容

### logout-button.tsx

- 新增 `DEFAULT_LOGOUT_REDIRECT_URI = '/'` 常量，`postLogoutRedirectUri` prop 默认值由「不传」改为 `'/'`
- 行为变化：点击退出登录 → 默认携带隐藏字段 `post_logout_redirect_uri='/'`（服务端白名单 OQ-007 内）→ 服务端返回 end_session 自动提交页 → 自动 POST 到 IDP `end_session_endpoint` → 全局登出后回跳我方首页 `/`
- 保留可覆盖能力：传其他同源相对路径（服务端白名单内）可改回跳目标；传空串/`undefined` 不携带字段，走原本地登出 200 分支

## 涉及文件

## 后续影响 / 注意事项

IDP 端回跳 `/` 为相对路径，依赖 IDP 将 `post_logout_redirect_uri` 解析回我方首页（OQ-007 方案 A 白名单仅首页）；若 IDP 不支持相对回跳，需改为配置我方 `publicRedirectUri` 绝对地址并纳入白名单。
