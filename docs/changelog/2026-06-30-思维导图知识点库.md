# 思维导图按知识点体系库分层级生成

**日期**：2026-06-30
**类型**：新增 | 优化
**影响范围**：skill prompt 加载机制、第五章思维导图生成规则、orchestrator 编排层

## 变更背景

此前 skill 第五章"知识点思维导图"由 LLM 根据自身理解自由组织知识点，存在两个问题：
1. **分类不系统**：LLM 自由发挥的节点命名与分类缺乏统一的层级结构，难以形成稳定可检索的知识体系
2. **难以维护**：知识点散落在 LLM 输出中，无法集中更新与扩充

用户汇总了 9 大类 C++ 知识点体系（基础语法、内存与指针、函数、OOP、模板、STL、数据结构与算法、现代 C++ 与并发、文件与流 I/O），希望：
- 思维导图按此知识点库分层级生成
- 知识点内容独立存储，便于后续更新维护时 skill 自动调用

## 变更内容

### 新增 C++ 知识点体系库

- 新增 `app/lib/ai/data/cpp-knowledge.md`，以 Markdown 格式存储 9 大类知识点
- 层级结构：大类标题（`##`）→ 子分类标题（`###`）→ 具体知识点（`-`）
- 文件头部声明维护方式与思维导图层级约定
- 维护方式：直接编辑本文件即可，无需修改 skill prompt

### orchestrator.ts：新增知识点库加载机制

- 新增 `KNOWLEDGE_BASE_PATH` 常量指向知识点库文件
- 新增 `knowledgeBaseCache` 成员与 `loadKnowledgeBase()` 方法（带缓存，与 `loadSkillPrompt()` 同款实现）
- `compute()` 方法中并行加载 skill prompt 与知识点库，拼接为 `fullPrompt`：
  - skill prompt 在前，知识点库以 `## C++ 知识点体系库（第五章思维导图必须按此库的层级组织节点）` 标题追加在后
  - 知识点库加载失败时回退到纯 skill prompt（不阻断流程）
- 生成阶段与格式重试阶段均使用 `fullPrompt`，保证思维导图规则一致

### gesp6-skill.md：第五章思维导图规则重构

第五章新增三个规范小节：

1. **知识点选取规范**：
   - 必须从知识点库挑选，禁止自行编造分类
   - 仅列出与本题相关的知识大类与子分类，无关大类不列出
   - 第四层具体知识点仅列出本题实际用到的

2. **思维导图层级结构**：明确四级层级
   - 第一层：根节点为题目名称（≤8 字）
   - 第二层：知识点库 9 大类之一
   - 第三层：该大类下的子分类
   - 第四层：该子分类下的具体知识点

3. **节点命名规则**：
   - 第二/三/四层分别使用知识点库中的大类标题、子分类标题、列表项原文
   - 禁止改写、合并或拆分知识点库中的命名

4. **讲解卡片选取规则**：
   - 仅为第四层具体知识点（叶子节点）生成讲解卡片
   - 第二/三层不生成讲解卡片，避免空卡片
   - 讲解内容结合本题代码场景

示例 mindmap 与 HTML 结构同步更新为四级层级版本。

## 后续影响 / 注意事项

1. **dev server 需重启**：`orchestrator.ts` 中 `knowledgeBaseCache` 与 `skillPromptCache` 均为进程级缓存，首次加载后驻留内存。修改知识点库或 skill prompt 后必须重启 dev server 才能生效。
2. **知识点库维护（双处同步）**：知识点库目前存在两份，更新时**两处都要修改**：
   - `app/lib/ai/data/cpp-knowledge.md` — 供 orchestrator 自动加载拼接进 prompt
   - `.trae/skills/gesp6-solution/SKILL.md` 末尾"附录：C++ 知识点体系库" — 供 Trae skill 独立运行时 LLM 直接读取
   - 两处内容必须保持一致，附录开头已注明同步关系
3. **prompt 长度增加**：拼接知识点库后 prompt 总长度约增加 3 KB，对支持长上下文的 LLM 影响可忽略。
4. **与第四章流程图的差异**：第四章流程图仍由 LLM 根据代码逻辑自由组织（流程图依赖具体算法实现，不适合用统一模板约束）；只有第五章思维导图受知识点库约束。
5. **向后兼容**：知识点库加载失败时回退到纯 skill prompt，旧逻辑不受影响。
6. **Trae skill 独立性**：`.trae/skills/gesp6-solution/SKILL.md` 是 Trae skill 系统的入口文件，独立运行时不经过 orchestrator，因此知识点库内容必须内联到 SKILL.md 末尾（不能像 orchestrator 那样外部拼接）。
