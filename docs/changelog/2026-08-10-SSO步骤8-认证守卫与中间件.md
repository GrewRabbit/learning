# SSO 步骤 8：认证守卫与中间件粗检

**日期**：2026-08-10
**类型**：新增
**影响范围**：`/api/solve`（POST 认证）、`middleware.ts`（限流/认证顺序调整）、`/api/sso/*`（认证豁免）、`/login` 重定向

## 变更背景

SSO 集成架构 §11 步骤 8：将认证能力接入实际业务接口。此前 `/api/solve` 无任何认证，任意客户端可直接触发 LLM 调用消耗成本；middleware 的认证钩子 `isAuthenticated` 恒为 true 属占位实现。本步骤落地 M5 认证守卫（Node 层完整验签）与 middleware 粗检（Edge 层仅 exp 解码），形成「粗检拦截 → 精检验证」两层防线，与 M2 id-token-verifier 共用 discoveryService JWKS 拉取路径（AR1-006）。

## 变更内容

### M5 认证守卫 `app/lib/auth/guard.ts`（新增）

- `requireAuth(request: Request): Promise<ServiceResult<AccessTokenClaims>>`：从 Cookie 读取 `sso_access_token`，本地 JWT 验签（jose `jwtVerify`：RS256 + kid 匹配 + iss === SSO issuer + aud === SSO clientId + exp，fail-closed）
- Cookie 解析手写实现（不引第三方库），URL 编码非法视为无此 cookie
- JWKS 经 `discoveryService.getJwks(kid)` 拉取（唯一路径，kid 未命中强制刷新缓存）
- 错误码（token spec FR-025，不重复定义）：无 token / 解析失败 / 验签失败 / iss、aud 不符 / 结构非法 → `AUTH_SESSION_INVALID`（401）；exp 过期 → `AUTH_TOKEN_EXPIRED`（401，AD-04 过期不续期）

### `middleware.ts` 认证粗检（修改）

- 顺序调整（AR1-001）：限流移至认证检查之前，未认证请求同样消耗配额
- 认证粗检仅对受保护路由 `/api/solve`：读 `sso_access_token` cookie，仅 base64url 解码 JWT payload 取 exp（Web API `atob`/`TextDecoder`，不验签、不引用 `SSO_CLIENT_SECRET` 等密钥环境变量，FR-024），不存在/解码失败/过期 → 302 重定向 `/login`（[locale] 未落地维持顶层，AR1-009）
- `/api/sso/*` 不在受保护前缀内，天然豁免粗检（避免自身 302 死循环，AR2-001），但仍走限流
- `/api/health` 豁免限流（保持现状）；matcher 保持 `['/api/:path*']`
- 移除恒 true 的 `isAuthenticated` 钩子（替换为 `isSessionValid` 粗检实现）
- Edge 约束：仅 console 不用 logger、禁 Node 原生模块、仅 Web API

### `/api/solve/route.ts` 接入（修改，仅 POST）

- POST 开头（Zod 校验之前）调用 `requireAuth(request)`；失败 → 401 `{ success: false, error: { code, message } }`（`AUTH_TOKEN_EXPIRED` / `AUTH_SESSION_INVALID` 均 401），并记 `logger.warn('[SolveRoute] 认证失败', { code, elapsedMs })`
- 成功解出 `sub` 加入「收到请求」日志（仅日志关联，不泄露敏感值）
- GET / DELETE 不动（轮询/取消不属受保护操作，避免破坏前端轮询流程）

## 后续影响 / 注意事项

- 受保护路由 POST 现要求携带有效 `sso_access_token` cookie（未登录 → 302 至 /login；token 过期 → 401 AUTH_TOKEN_EXPIRED），前端需确保在 SSO 登录流程完成后调用
- 刷新令牌逻辑（refresh 路由 / token-refresher）保持独立，本步骤不联动
- `[locale]` 国际化落地后需将 middleware 302 目标改为 `/${locale}/login`（AR1-009 已注释）
