# Header 布局细化与品牌图片修复

**日期**：2026-08-11
**类型**：优化（含修复）
**影响范围**：Header 组件布局（components/site-header/*、components/ui/*）、middleware.ts 静态资源拦截、全站品牌图片显示

## 变更背景

Header 首版上线后收到三点反馈：① Logo 未贴屏幕最左、注册/登录与用户图标未贴最右；② 图标整体偏大需再小一号；③ 首页已有居中大 Logo，顶部小 Logo 与其重复。同时发现全站品牌图片不显示——`/_next/image` 优化器内部回源 `/happyrabbit-logo.png` 时被 middleware 拦截 302 跳登录，导致优化失败 400。

## 变更内容

### Header 布局细化

- `components/site-header/header-bar.tsx`：外层容器由 `max-w-6xl` 改为 `flex h-12 w-full items-center justify-between px-4 sm:px-6`，Logo 贴屏幕最左、右侧操作区贴最右（保留安全留白）；首页（`/`、`/{en|zh}`）仅渲染右侧注册/登录或用户菜单，不渲染重复 Logo；注册/登录按钮改 `size="xs"`。
- `components/auth/login-button.tsx`：新增可选 `size` prop（default/sm/lg/xs/icon），透传 Button；Header 传 xs，登录页保持默认尺寸。
- `components/ui/button.tsx`：新增 `xs` size 变体（`h-7 rounded-md px-2.5 text-xs`）。
- `components/ui/logo.tsx`：`sm` 尺寸由 `h-8/10` 收敛为 `h-6/7`，srcSet 同步 32/40px → 24/28px。
- `components/site-header/user-menu.tsx`：用户图标按钮 `h-8 w-8 rounded-full`，User 图标 `h-5 w-5` → `h-4 w-4`。
- `components/site-header/header-utils.ts`：新增 `isHomePath(pathname)`（规范化去尾斜杠后恒等 '' 或匹配 `^/(en|zh)$`），配套单测 `header-utils.test.ts` 补充 isHomePath 用例。

### 品牌图片修复

- `middleware.ts` matcher 负向断言追加 `happyrabbit-logo.png`（`_next/image` 优化器内部回源的品牌 Logo，路径被拦则优化 400）与 `_shared`（public 静态共享目录：Mermaid 脚本/字体，srcDoc iframe 同源加载）。
- `__tests__/middleware.test.ts` matcher 断言同步更新。
