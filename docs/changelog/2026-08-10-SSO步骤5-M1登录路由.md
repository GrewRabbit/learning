# SSO 步骤5：登录路由模块 M1（authorize + callback）

**日期**：2026-08-10
**类型**：新增
**影响范围**：`/api/sso/authorize`、`/api/sso/callback` 路由；`app/lib/sso/` 服务层新增编排模块

## 变更背景

实施 SSO 集成步骤 5（架构 §11 步骤 5 / 模块 M1）：SP-Initiated Authorization Code + PKCE 登录流程的服务端路由。前端登录页（步骤 9）依赖这两个端点完成发起登录与回调换取会话。

## 变更内容

### `/api/sso/authorize`（POST 登录发起）

- 仅 POST（GET 405）；form body 经 `authorizeFormSchema` 校验，失败 400 `AUTH_LOGIN_MISSING_PARAMS`
- 服务端生成权威 PKCE 参数：`code_verifier`（64）、`code_challenge`（S256）、`state`（≥32）、`nonce`（≥32）
- 状态双写（FR-003）：服务端写一次性状态 cookie `sso_authorize_state`（httpOnly + sameSite=lax + path=/ + maxAge 10min，JSON 含 code_verifier/state/nonce/returnTo 四字段，为权威副本；sessionStorage 由前端负责）
- `returnTo` 规范化（FR-005/023）：仅同源相对路径，`javascript:`/`data:`/协议相对/跨域一律忽略回默认 `/`
- 构造 authorize URL（FR-004）→ 302 authorization_endpoint（Discovery 获取失败 → 500 `AUTH_IDP_DISCOVERY_FAILED`）

### `/api/sso/callback`（GET 回调）+ `app/lib/sso/callback-flow.ts`（编排下沉，R-08）

- query 经 `callbackQuerySchema` 校验，缺参 400 `AUTH_LOGIN_MISSING_PARAMS`
- `error` 参数：`access_denied` → 400 友好提示 + 清状态 cookie 不交换；其他 → 400 `AUTH_LOGIN_IDP_ERROR`
- 状态 cookie 恢复与 `state` 校验（FR-007，不一致 → 400 `AUTH_LOGIN_STATE_MISMATCH`，一次性，成功后清）
- `iss` 校验（FR-008，RFC 9207）：不一致 → 400 `AUTH_LOGIN_ISS_MISMATCH`
- 服务端令牌交换（FR-009）：`oauthClient.exchangeCode({code, redirect_uri: publicRedirectUri, code_verifier})`；失败 → 400 `AUTH_TOKEN_EXCHANGE_FAILED`（网络失败透传 502 `AUTH_LOGIN_IDP_UNREACHABLE`），不泄露 IDP 细节（FR-010/FR-026）
- id_token 验证（FR-011）：`idTokenVerifier.verifyIdToken(idToken, nonce)`，strict 失败 → 401 `AUTH_ID_TOKEN_INVALID`
- userinfo（FR-013）：sub 与 id_token.sub 一致，不一致/失败 → 401；userinfo 401/失败记日志（续期归步骤 6）
- 会话 cookie（FR-015）：`sso_access_token`（maxAge=expires_in，默认 900s）、`sso_refresh_token`（30 天，响应含 refresh_token 时）、`sso_id_token`（30 天），均 httpOnly + secure(生产) + sameSite=lax + path=/；同时清状态 cookie
- 302 → returnTo（恢复后过 FR-023 复检，非法回 `/`）

### `app/lib/sso/token-cookie.ts`（新服务层模块）

- 状态/会话 cookie 名称与安全属性常量、`isSafeReturnTo`（开放重定向校验）、`serializeStateCookie`/`parseStateCookie`、`setStateCookie`/`clearStateCookie`、`setSessionCookies`
